# Discussion

This directory holds **pinned discussion templates and category guides** for the FEDMON: NO MERCY GitHub Discussions space.

GitHub Discussions categories are configured in the repo UI (Settings → Features → Discussions → Set up). The files here are reference templates you can paste when starting a discussion, and guides for what belongs in each category.

---

## Suggested categories

| Category | What belongs | Template |
|----------|--------------|----------|
| 📣 Announcements | Releases, devlogs, milestones | — (maintainer-only) |
| 💡 Ideas & feature requests | Propose game/page features | `idea.md` |
| 📖 Lore & worldbuilding | World discussion, creature ideas (non-coded) | `lore.md` |
| 🙋 Q&A | Questions (check FAQ first) | `qa.md` |
| 🛠️ Show & tell | Fan art, streams, playtest reports | `showcase.md` |

## Rules (all categories)

1. **Be kind.** The game is brutal; the community isn't. See [Code of Conduct](../CODE_OF_CONDUCT.md).
2. **No racially coded language** in lore, names, or locations. (ADR-005)
3. **Search before posting.** Check the [FAQ](../FAQ.md) and existing discussions.
4. **One topic per discussion.** Don't bundle unrelated questions.
5. **Bugs → issues, not discussions.** Use the bug report template.
6. **Security → private report.** Never post vulnerabilities publicly. See [SECURITY.md](../SECURITY.md).

---

## Maintainer notes

- Pin the welcome post (`.github/DISCUSSION_WELCOME_README.md`) in Announcements.
- Mark answered Q&A and lock if needed.
- Move bug reports posted as discussions to Issues.
