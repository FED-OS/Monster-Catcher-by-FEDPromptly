## Conventions

- Wiki pages are markdown, GitHub-flavored.
- Link to repo docs with relative paths when mirroring (e.g. `[CONTRIBUTING](../CONTRIBUTING.md)` works in-repo; in the GitHub Wiki use full URLs).
- Lore additions must follow the no-racially-coded-language rule (ADR-005).
- Game-design pages describe **intended** mechanics; the promo page may show simplified versions.
