# Glossary

Terms used across FEDMON: NO MERCY docs and the promo page.

| Term | Meaning |
|------|---------|
| **FED / FEDMON** | The game's identity prefix; evokes the legal/jurisdictional system (arrest, heat, fines). Chosen to avoid racially coded alternatives (ADR-005). |
| **No free healing** | Core pillar — healing always costs money. Non-negotiable. |
| **Dual combat** | Trainer and creature fight together in the same encounter. |
| **SYNC** | Energy built during combat; gates the ULT move. |
| **ULT** | Signature finisher; requires full SYNC. |
| **Heat** | Police attention meter; rises with unprovoked aggression. Trips arrest. |
| **Arrest** | Consequence of high heat: cash halved, car towed, fines double per offense. |
| **Daily burn** | The daily cost of survival (food, shelter, upkeep). |
| **Loan shark** | In-fiction lender; compounding interest, escalating consequences. Satire of predatory lending — NOT real-money microtransactions. |
| **Property / proof of address** | In-game real estate; required legally, costs 2× income, foreclosed on missed payments. |
| **PC banking** | Storing money in the PC to protect it from arrest confiscation. |
| **Wire fee** | 15% charge on bank transfers. |
| **4th form** | Starter-only 1-turn evolution: double highest stat, halve lowest. |
| **FED- form** | The third evolution stage; prefixed "FED-" (e.g. FED-Inferno). |
| **Rail** | The fixed left HUD on the promo page showing live readouts. |
| **Scroll-snap** | The page's section-by-section snapping scroll behavior. |
| **Combat HUD** | The interactive canvas fight on the promo page (section 02). |
| **Mech deck** | The horizontal scroll-snap card carousel (section 03). |
| **Grain** | The inline SVG fractal noise overlay. |
| **Easter egg (F)** | Press F on the boot section to glitch the title and charge SYNC. |
| **ADR** | Architecture Decision Record — see [ADR.md](../ADR.md). |
| **No reused layouts** | Policy (ADR-007): visual changes must be structural, not restyles. |
